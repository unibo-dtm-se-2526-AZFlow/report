# AZFlow — Software Engineering Report

This repository contains the final project report for **AZFlow**, a healthcare queue management system developed for the Software Engineering course of the Digital Transformation Management programme at the University of Bologna.

The report documents the project from concept and requirements to architecture, implementation, validation, release, deployment and CI/CD, together with user/developer guides, self-evaluation and future work.

## Report structure

The report is organised under `sections/`:

1. Concept
2. Requirements
3. Design
4. Development
5. Validation
6. Release
7. Deployment
8. CI/CD
9. User Guide
10. Developer Guide
11. Self-evaluation
12. Future work

Diagrams, screenshots and other visual material are stored in `pictures/`.

## Local preview

The published report is generated with Jekyll and the `just-the-docs` theme. To preview it locally, install Ruby/Bundler and run from the repository root:

```bash
bundle install
bundle exec jekyll serve
```

The local site is normally available at:

```text
http://127.0.0.1:4000
```

## Publishing

The report website is built and published through the repository's GitHub Pages configuration. Changes to the report are made in Markdown and become visible on the published site after they are committed and pushed and the Pages build completes.
