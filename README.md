# AZFlow — Software Engineering Report

This repository contains the report for **AZFlow**, a healthcare queue-management system developed for the Software Engineering course of the Digital Transformation Management programme at the University of Bologna (2025/2026).

The report documents the project concept, requirements, architecture, implementation, validation, release and deployment, together with user and developer guides, self-evaluation and future work.

## Local preview

The report is written in Markdown and published with Jekyll and the `just-the-docs` theme. To preview it locally:

```bash
bundle install
bundle exec jekyll serve
```

Open `http://127.0.0.1:4000` in a browser.
